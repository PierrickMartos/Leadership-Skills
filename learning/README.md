# Learning

Skills for deeply understanding any subject — a concept, a domain, a system, a paper, a piece of code. Explains what it means and why it matters in plain language, using the Feynman Technique, so it actually clicks.

## Skills

| Skill | Purpose |
|-------|---------|
| `learn-deeply` | Explain any subject in the simplest faithful terms using the Feynman Technique — big picture, plain-language walkthrough, and where to go deeper. |

## HTML output

By default `learn-deeply` answers inline. You can also ask for a rendered HTML page ("as
HTML", "as a page", "export this"), and when an answer includes a diagram the skill offers
one. HTML pages are written to `./learn-deeply/` in your working directory (you may want to
git-ignore that folder) and, on local macOS, opened in your browser. The diagram renders
via mermaid.js from a CDN, so viewing it needs internet.
