# Communication

Skills for communicating clearly and having the conversations that matter — structuring written messages for impact, coaching leaders on communication, escalating problems without creating drama, and navigating difficult face-to-face conversations with directness and care.

## Skills

| Skill | Purpose |
|-------|---------|
| `bluf-communication` | Improve written communication using the BLUF framework — make messages clearer, more direct, and easier to act on. |
| `communication-coach` | Review any written communication shared by a leader — email, Slack message, document, or announcement — and give actionable, specific feedback grounded in proven leadership communication principles. |
| `delegate-well` | Pressure-test whether work should be delegated and to whom, close the context gaps that cause rework, then draft the handoff message. Based on Wes Kao's [6 questions to ask before delegating](https://newsletter.weskao.com/p/before-you-delegate-ask-yourself). |
| `difficult-conversations` | Structure and prepare for high-stakes conversations you've been avoiding — feedback, underperformance, conflict. |
| `escalate-without-drama` | Helps you escalate a problem — something off track, a blocked dependency, unclear ownership, or a team that isn't moving — without sounding political, blamey, or alarmist. |
| `reframe-for-execs` | Compress and reframe a detailed or operational draft into a crisp executive-ready message. |
